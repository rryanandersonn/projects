# Ryan Anderson: personal site

Free static site on GitHub Pages with a built-in visual editor.

- `admin.html`: the editor (projects, home page sections, design, backup)
- `index.html` / `project.html`: the public pages
- `app.js` / `style.css`: shared rendering and styles (themed from the editor)
- `projects.json`: all content and settings (written by the editor)
- `images/`: uploaded images

Open `/admin.html` on the live site, connect with a fine-grained GitHub token
(this repo only, Contents: read & write), edit, then press Publish.
